# 全世界共通抱腹絶倒だじゃれ自動生成プログラム
**Global Dad Joke Generator**

## 概要
このプログラムは、人生に更なる笑いを求めるすべての人々のために作られた、シンプルかつ強力なだじゃれ自動生成ツールです。  
実行するたびに、世界最高峰のジョークをあなたにお届けします。  

## 特徴
  
* **シンプル**: コマンド一つでだじゃれを生成できます。
* **くどい笑い**: 100個のだじゃれを収録しているため、実行するたび異なるダジャレが楽しめます。
* **軽量**: 必要なのはPythonだけ！  

## 動作環境

* Python 3.13 以上
* pip

## インストール方法

1. リポジトリのクローン
   ```bash
   git clone https://github.com/riporippo/B3_github_practice_1.git
   ```
2. ディレクトリに移動
   ```bash
   cd B3_github_practice_1
   ```

## 使い方

インストールが完了したら、以下のコマンドを実行する。

```bash
python joke.py
```
